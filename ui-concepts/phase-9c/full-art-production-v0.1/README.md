## 边界

本目录只制作当前配置中尚无专用位图的内容，不替换 G2 已批准的 14 张非
Token 随从、3 个 Token、4 张法术、3 件遗珍与缺图诊断图。配置中的
`artId` / `uiIconId` 保持不变。

生成结果先保存于 `masters/`；经尺寸、构图、重复主体、文字与水印检查后，
才复制到 Unity Runtime 路径。图片进入 Runtime 目录不等于通过人工许可，
也不等于 `Runtime Ready`。

## 共同视觉约束

1. 温暖手绘水彩、深胡桃色或彩色墨线、纤维象牙纸、可见纸纹与不规则笔缘。
2. 主体使用宽阔、可在缩略图辨认的一级形状；背景通过简化形状和降低细节保持
   安静，不得通过整体降曝光实现。
3. 卡图的关键脸部、轮廓、手持物和机制钩子全部留在中央 80% 安全区；
   外圈 7% 不放不可裁切信息。
4. 不生成卡框、UI、标题条、文字、字母、数字、可读书写、徽标、水印或签名。
5. 避免照片写实、光滑数字卡牌渲染、动漫/抽卡风、儿童吉祥物风与无关粒子。
6. 同种族共享媒介、材料和一级几何，但每个内容必须有独立主体、姿态、道具与
   场景，不把已有锚点换色复刻。
7. 卡面至少 50% 为亮部或中亮部，近黑面积不超过约 12%；普通环境背景至少
   60% 为亮部或中亮部，近黑面积不超过约 8%。
8. 默认使用晨间至下午的漫射日光和彩色开放阴影；保留浅纸、天空蓝、叶绿、
   暖赭或灰蓝。火焰、魔法和灯具只作局部强调，不得作为主光。
9. 禁止以夜景、黄昏、暗区留白、暗色外缘、黑色暗角、烟尘或全局棕黑调色制造
   气氛；UI 留白必须通过减少细节实现。

## 历史随从硬约束（已停用）

以下内容仅解释旧图片的生成方式，不再约束 v0.3。尤其是荒灵的树皮、根、叶、
苔藓与动物骨架组合规则已经取消。

- 铸魂：由炉火灵性驱动的铸造生命；文化与视觉语义围绕锻造、炉火、盾甲、修复、
  誓约和手工金属。具体身体结构不作全族硬限制，可以采用完整手掌、连贯甲体或
  其他符合身份、阶级、能力和叙事的结构。避免科幻机器人、活塞、线路、齿轮堆、
  蒸汽朋克、恶魔和哥特尖刺。
- 荒灵：树皮、根、叶、苔与自然动物骨架形成分叉、破边有机曲线；避免萌宠、
  人形树精套壳、霓虹绿和对称法阵。
- 星契：靛蓝、纸白、柔紫与少量旧黄铜；轻薄开放圆弧、纵向织带与充足负空间；
  避免封闭头光环、厚重机械、满袍星点和宇宙爆炸。
- 旅团：实用旅行装备、补丁布、旧皮革、木材与不对称负重；避免全套重甲、
  神圣英雄姿态、过量武器和与铸魂混淆的金属块体。

## 生产检查

每项至少检查：内容语义、种族/类别、主体数量、指定数量约束、轮廓差异、中央
安全区、缩略图可读性、无文字/水印、文件尺寸、RGB 模式、SHA-256、目标路径。
不合格项使用一次只改一个问题的受控编辑，不以整批重写掩盖单项问题。
