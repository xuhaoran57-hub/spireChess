## 星契背景

星契是与星海、命运轨迹和古代天体知识签订契约的观测者、学者、商人和施法者。
他们通过星盘、星图、棱镜书页和仪式契约操纵刷新、法术、发现与永久成长。

星契是知识、职业、商业与施法传统共同组成的文化阵营，不是特殊生物物种。常规
角色保持面部、双手和职业动作清楚的人形或亲和型类人；角色差异通过年龄、学派、
服装、身份、姿态与知识工具表达，不通过异形化表达。

## 一级识别

常规星契卡面至少清楚出现以下元素中的两类：

1. 天体观测：开放星盘、星图、星轨节点、观测镜或月相轮；
2. 命运知识：命运轨迹、因果分支、被固定的成长节点或仪式契约；
3. 法术载体：棱镜书页、无字法术页、折射光束或知识卷轴；
4. 契约行为：签订、交换、选择、记录、调度或仪式确认。

这些元素必须服务角色的职业动作，不作为背景装饰堆叠。星点、月相和蓝紫色本身
不能单独承担星契识别。

## 人物与服装

- 默认使用观测者、学者、星图商人、档案员、调度者或契约施法者；
- 服装采用流动的学者长袍、观测披肩、仪式织带、契约绶带、卷轴匣与轻型书袋；
- 靛蓝、纸白、柔紫、珍珠蓝和少量旧黄铜构成主要阵营色；
- 面部、眼神和双手必须可读，人物正在观察、选择、记录或施法；
- 星盘、月轮、书页、棱镜和契约器具始终是外部知识工具，不成为身体部件。

普通工坊围裙、密集工具腰带、锤具、扳手、木工台和机械修理姿态不属于星契的
默认职业语言。交易发生在知识、法术和命运契约之间，不表现为普通商品制作。

## 场景

优先使用：

- 白昼高地观测台；
- 天空书库或星图档案廊；
- 星图与法术交易亭；
- 命运契约庭；
- 开放式月相学派露台。

场景保持旅行绘本的开放日光、浅天空和低细节远景。人物头肩和关键工具后方使用
大块天空、浅云、帆布或纸色净空，不使用普通作坊和拥挤货摊作为主要环境。

## 机制视觉语法

| 机制 | 星契视觉语言 |
|---|---|
| 刷新 | 星盘转动，星图节点或命运路径重新排列 |
| 使用法术 | 棱镜书页展开并折射一段法术轨迹 |
| 发现 | 两到三个命运分支或知识选项短暂展开 |
| 获得法术 | 一张新的无字棱镜书页从星图或契约中显现 |
| 永久成长 | 一段命运轨迹凝固为稳定、明亮的新星图节点 |
| 护盾 | 月相弧或星轨形成透明保护层 |
| 溅射 | 棱镜光或命运轨迹向多个低细节目标分支 |
| 购买/交换 | 仪式契约或知识印记在角色与法术载体之间完成交换 |

每张卡面只选取与真实配置直接相关的一个主要机制动作和最多两个次要提示，不把
刷新、法术、发现、交易、护盾和战斗预览全部放在同一张图中。

## 主体—背景分离

- 人物或主角占画面高度约 50%–70%，脸部与核心动作位于中央 60%；
- 至少约 70% 的主体轮廓面对浅天空、帆布、纸色墙面或其他大片简化背景；
- 人物使用更深、更完整的胡桃色/靛蓝轮廓和一个清楚局部主色；
- 星图和命运轨迹可以发光，但背景的边缘与纹理密度仍低于主体；
- 缩小至 160×128 后，先读到人物职业，再读到星盘、书页或契约机制。

## 非常规形态

兽形、器物形或抽象星契生命只有在正式卡牌配置和单卡设定明确要求时才允许使用，
并需单独审核。不得为了同族轮廓多样性由生成模型自行添加动物头、无脸面具、
器物身体、额外肢体或满身星纹。

## v0.3.1 星契验收

星契图片除通过 v0.3 通用门槛外，还必须满足：

1. 正式卡 `id / name / tier / description / artId` 与 Prompt 清单一致；
2. 不看卡名也能识别为天体知识、命运契约或法术研究职业；
3. 至少两类一级识别元素可见；
4. 没有普通工匠、修理工或杂货商的主导视觉语言；
5. 天体工具、书页和轨迹保持为外部知识工具；
6. 主角在 160×128 缩略图中先于背景和机制特效被识别。
