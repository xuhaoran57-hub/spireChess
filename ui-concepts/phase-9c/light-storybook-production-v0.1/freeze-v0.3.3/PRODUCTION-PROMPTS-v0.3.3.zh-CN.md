## 拼装顺序

随从使用“共同卡面块 + 阵营块 + 单卡变量”。法术使用“共同卡面块 + 法术块 +
单卡变量”。背景使用“共同背景块 + 对应场景变量”。

图片 1 是唯一图像参考。不得输入旧随从、旧卡面、角色锚点、前轮图片或其他内容
参考。图片 1 只控制媒介、纸纹、线条、色板和曝光，不复制人物、道具、排版与构图。

## 共同卡面块

```text
用途：风格化游戏概念美术。

资产类型：约 5:4 横构图的完整卡面插画母版，只生成全出血插画，不生成卡框。

图片 1 是唯一图像参考。只采用冻结的明亮旅行绘本视觉语言：轻盈手绘水彩和
水粉、彩色墨线、暖象牙纸、可见纤维纸纹、不规则笔缘、松弛的胡桃色轮廓线、
清澈蓝绿与赭石色板。不得复制参考图的拼贴、人物、物件、文字或构图。

一个明确主角或一个主要物件组，占画面约 50%–70%。身份核心位于中央 60%，
所有必要信息位于中央 80%，外圈 7% 保持安全。至少约 70% 的一级轮廓面对连续、
低细节背景。头部、手部和关键动作背后使用浅天空、纸色墙面、帆布、雾化远山
或其他简化色块。主体轮廓、明度、色温和纹理至少有两项明显强于紧邻背景。

使用晨间至下午的漫射白昼作为主光。亮部或中亮部至少占 50%，近黑面积低于
12%。阴影开放、柔和并保留颜色。魔法、灵魂和炉火只作为局部强调。

次要盟友、召唤物、预览或机制物件最多两个，单体不超过主角约四分之一，并降低
饱和度、线条完整度和细节。先读到主体身份，再读到机制关系。

不生成卡框、界面、标题条、按钮、可读文字、字母、数字、Logo、签名或水印。
不使用照片写实、光滑 3D、动漫抽卡渲染或厚重不透明数字绘画。
```

## 阵营块

### 铸魂

```text
阵营：铸魂。

主题是灵魂被封入铠甲、兵器和机关中的造物。画面必须清楚表现发光灵魂正在驱动
锻造生命，而不是普通人穿甲或没有灵魂语义的机器人。机制可使用护盾、嘲讽、
亡语、获得或失去护盾、相邻随从和受击后的共鸣。

身体结构由单卡身份决定。不得给全族设置固定的空腔、断裂甲片、夹具、肢体数量、
盾牌数量或武器数量。不得使用月相、星盘和占星纹样承担一级识别。
```

### 荒灵

```text
阵营：荒灵。

主题是山林、兽魂、藤蔓与古老生命力。身份来自角色与山林、兽魂、祖灵和生死
循环的关系。机制可使用亡语、嘲讽、友方死亡、荒灵死亡、召唤物和死亡后增益。

主体外形由单卡身份决定，可以是可信动物、类人守林者、山野精怪或祖灵。正常
毛发、羽毛、皮肤、衣物和工具均可作为主要外观，不要求主体采用统一自然材质。
亡语与死亡使用无血腥的生命回声、风、光流或魂能表达。
```

### 星契

```text
阵营：星契。

星契是与星海、命运轨迹和古代天体知识签订契约的观测者、学者、商人和施法者。
他们通过星盘、星图、棱镜书页和仪式契约操纵刷新、法术、发现与永久成长。

常规角色使用面部、双手和职业动作清楚的人形或亲和型类人。角色通过年龄、学派、
服装、身份、姿态和知识工具区分，不通过异形化区分。画面至少清楚出现天体观测、
命运知识、法术载体、契约行为中的两类。星盘、月轮、书页、棱镜和契约器具始终
是外部工具。

优先使用白昼高地观测台、天空书库、星图档案廊、命运契约庭或开放月相学派。
不得以普通围裙、工具腰带、锤具、扳手、木工台或修理动作主导职业身份。
```

### 旅团

```text
阵营：旅团。

旅团是旅行者、医者、向导、佣兵、商贩和专业人士组成的跨地域共同体。至少显示
一个清楚职业、一种实用旅装，以及道路、营地、旧塔或山口等开放旅途环境。

使用可信角色身体。装备应使用过、修补过并适合长期携带；只保留与职业直接相关
的一到两件主要工具。不得把旅团表现为共享身体材质、生理结构、统一军装或固定
徽章的生物种族。
```

## 法术块

```text

计数使用清楚分离的无文字物件；刷新使用循环或重新排列的轨迹；发现使用两到
三个空间候选；永久成长使用凝固的新节点或固定光痕。

画面不依赖人物肖像，不表现成卡牌选择界面，不生成按钮、面板、可读符号或数字。
```

## 输出前检查

1. 只有冻结 Style Tile 一个图像输入；
2. 主体身份先于背景与特效被识别；
3. 亮度、近黑和轮廓净空达到冻结门槛；
4. 星契至少出现两类知识/契约识别，不像普通工匠；
5. 荒灵不依赖统一身体材质；
6. 铸魂不依赖固定身体结构；
7. 不新增旅团共同生理特征；
8. 没有卡框、界面、文字、Logo 或水印。
