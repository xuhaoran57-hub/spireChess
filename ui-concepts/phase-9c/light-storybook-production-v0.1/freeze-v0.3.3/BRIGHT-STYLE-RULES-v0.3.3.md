## 冻结边界

v0.3.3 冻结以下内容：

- 明亮旅行绘本的媒介、色板、曝光和纸张质感；
- 随从、法术和普通场景的亮度门槛；
- 主体与背景的层级分离规则；
- 四个阵营的身份边界和单卡语义输入方式；
- 普通/金色 × 紧凑/完整卡框布局及费用展示；
- 战斗立牌的居中覆盖裁切；
- 战斗立牌专用的明亮、边缘式护盾。

本版本不冻结新的全族身体模板、肢体数量、共同道具或旧随从内容参考。Unity
运行时材质效果尚未验收，因此状态为“离线冻结”，而不是“Unity 最终放行”。

## 视觉源与内容源

每次生成只允许一个图像参考：冻结 Style Tile。它只控制轻盈手绘水彩、水粉、
彩色墨线、暖象牙纸、纤维纸纹、开放日光和色板，不提供人物、道具或构图内容。

内容只来自：

1. 正式配置中的阵营、卡名、职业、能力和机制关系；
2. 本文件的阵营规则；
3. 单卡必要动作与最多两个次要机制提示。

不得输入旧随从图、旧卡面、角色锚点、前轮生成图或其他内容参考。不得把某张
成功样本的身体结构扩展成全族硬约束。

## 亮度与媒介

### 随从与法术

- 约 5:4 横构图；
- 缩放至 160×128 后，以 Rec.709 luma 统计；
- luma ≥ 85 的亮部或中亮部像素不少于 50%；
- luma < 25 的近黑像素少于 12%；
- 白昼漫射光是主光，魔法、灵魂和炉火仅作局部强调；
- 阴影保持蓝灰、青绿、紫灰或暖褐色相；
- 保留暖象牙纸、浅天空和透明水彩叠色。

### 主菜单、商店和地图

- 16:9 横构图；
- 普通场景建议亮部或中亮部不少于 60%，近黑少于 8%；
- UI 留白使用低细节浅色形状，不使用大面积暗区；
- 危险感、Boss 感和稀有度通过尺度、姿态、轮廓及局部色彩表达。

## 主体与背景分离

- 一个明确主角或一个主要物件组，占画面约 50%–70%；
- 身份核心位于中央 60%，必要信息位于中央 80%；
- 外圈 7% 不放必要信息；
- 至少约 70% 的一级轮廓面对连续、低细节背景；
- 头部、手部和关键动作背后不得堆叠高频枝叶、建筑线或其他角色轮廓；
- 主体与紧邻背景至少满足两项：明度差约 0.12、清楚的冷暖或色相分离、
  更完整的彩色轮廓线、背景纹理密度不超过主体约一半；
- 不通过整体降曝光、黑色暗角或纯黑阴影制造分离。

自动整体亮度通过不等于视觉通过。160×128 缩略图中必须先读到主体身份，再读到
机制和环境。

## 阵营冻结

### 铸魂

主题是灵魂被封入铠甲、兵器和机关中的造物。偏好护盾、嘲讽、亡语；主要联动是
获得或失去护盾、相邻随从和受击触发。画面必须能读出“灵魂驱动锻造物”，但不得
固定空心躯壳、断裂甲片、夹具、肢体数量、盾牌或武器数量。

### 荒灵

主题是山林、兽魂、藤蔓和古老生命力。偏好亡语、嘲讽；主要联动是友方死亡、
荒灵死亡、召唤物和死亡后增益。身份来自与山林、兽魂和生命循环的关系，不要求
主体由树叶、山石、藤蔓或任何统一材质组成。

### 星契

星契是与星海、命运轨迹和古代天体知识签订契约的观测者、学者、商人和施法者。
他们通过星盘、星图、棱镜书页和仪式契约操纵刷新、法术、发现与永久成长。
常规角色优先使用身份清楚的人形或亲和型类人；天体工具是外部知识工具。至少
出现天体观测、命运知识、法术载体、契约行为中的两类。不得默认异形化，也不得
滑向普通工匠、修理工或杂货制造者。

### 旅团

旅团是旅行者、医者、向导、佣兵、商贩和专业人士组成的共同体，不是生理种族。
身份来自清楚职业、实用旅装和开放旅途环境。角色不共享固定帽子、背包、徽章、
身体材质或军装。

## 法术冻结

- 使用“结果先于施法者”的物件叙事；
- 一个主要物件组，最多两个机制提示；
- 发现、刷新、计数与永久成长由无文字物件和空间关系表达；
- 不生成角色肖像依赖、卡牌 UI、按钮、可读文字、字母、数字、Logo 或水印。

## 卡框与战斗表现

### 卡框

- 冻结普通/金色 × 紧凑 160×240/完整 240×360 四种布局；
- 紧凑和完整布局均显示左上角费用；
- 当前随从商品费用显示 3，法术读取正式配置费用；
- 名称、种族、规则、等级、攻击和生命不得与费用徽章碰撞；
- 金色状态只改变卡框和数值表现，不替换法术为不存在的金色形态。

### 战斗立牌

- 立牌为 160×240，肖像遮罩为 120×192；
- 肖像使用 `AspectRatioFitter.AspectMode.EnvelopeParent` 居中覆盖裁切；
- 不拉伸原画，不把主体推向遮罩边缘；
- 战斗护盾使用独立 Catalog 字段，不替换卡面护盾；
- 护盾采用浅蓝与象牙白边缘高光，中心透明，不能压暗主体；
- 当前白色叠色 alpha 冻结为 0.78，Unity 中仍需检查 Additive 过曝。

## 变更控制

以下任一变化必须新建版本，不得静默改写 v0.3.3：

- 更换 Style Tile 或增加第二张图像参考；
- 修改亮度、近黑、主体占比或轮廓净空门槛；
- 恢复全族身体硬约束或旧内容参考；
- 移除紧凑卡费用；
- 改回拉伸式战斗肖像；
- 改为中心不透明或会压暗主体的战斗护盾；
- 替换任一登记基线文件。

改动后应生成 v0.3.4 或更高版本，并重新产出卡矩阵、场景压力图和校验报告。
