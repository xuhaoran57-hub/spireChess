## 共同块

每张图只使用冻结 Style Tile 作为图像参考，只继承明亮旅行绘本的水彩/水粉、
暖象牙纸纹、彩色墨线、开放日光和色板；不得复制参考图中的人物、物件、文字、
UI 或构图。

输出是约 5:4 横构图的 Unity 卡牌随从插画母版，不含卡框。一个主角占画面
约 50%–70%，身份和关键动作位于中央 80%，外圈 7% 不放必要信息，至少约 70%
一级轮廓面对连续低细节背景。白昼漫射光为主，魔法只作局部强调。

共同禁止：暗场、黑色暗角、卡框、UI、可读文字、字母、数字、加号、箭头、
符文、Logo、签名和水印。

## 单卡变量

### 铜环学徒

小型年轻的铸魂造物，灵魂封在完整连贯的手工铜铁铠甲中。学徒举起简单铜环，
向一个低细节友方轮廓送出鼠尾草绿与浅蓝生命流，表达战斗开始时给予相邻友方
本场生命。初稿中的加号已经移除，最终稿只保留叶片状生命微粒和圆形水彩光。

### 炉心火种

紧凑敏捷的铸魂造物，胸口是克制橙色炉心。浅蓝护盾刚从肩部破裂，释放的能量
汇入更明亮有力的攻击手臂与短剑，表达失去护盾后本场增加攻击。

### 星尘随侍

年轻人形星契观测随侍，穿靛蓝与象牙白学者旅行服，维护外置黄铜星盘和两条
独立星图轨迹；第二条轨迹稳定时，一个永久星结固定在腰带上，表达第二次刷新
后的永久成长。

### 观星学徒

年轻人形星契观测学徒，打开无字棱镜星图并转动外置黄铜月轮。一条圆形轨迹
释放并开始新循环，表达战吼给予下一次免费刷新；同时保留观测与契约知识身份。

### 流浪剑客

穿补丁赭石和褪色蓝绿旅行服的独立剑客，带实用轻护具、旧靴、铺盖和一柄完整
长剑。在日照旅团营地边缘准备离队，一枚无标记旧铜币落入手中，表达出售时
额外获得金币。

### 裂爪幼兽

自然可信的幼年山猫，正常毛发、四足、长尾和猫科面部。一个新召唤的小型友善
兽魂在身后形成，前爪接住琥珀绿色生命轨迹，并留下一个稳定爪痕光，表达召唤
带来的本场攻击与首次永久攻击。

### 苔痕守苗

扎根于苔藓土团中的小型幼苗守护灵，具有友善面部和两簇叶片。一个低细节友方
兽魂消散并释放生命波；较宽波纹使叶片临时茂盛，较小稳定苔环固定在茎部，
表达友方荒灵死亡后的本场生命与首次永久生命。
