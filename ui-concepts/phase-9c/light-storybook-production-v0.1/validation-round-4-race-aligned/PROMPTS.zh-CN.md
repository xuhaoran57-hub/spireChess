# Round 4 种族校准提示词

三张卡面均只输入冻结风格图：

`../../../phase-9b/style-tiles/style-tile-d-wandering-storybook-v0.1.png`

未输入现有随从、旧卡面、角色锚点或 Round 3 图片。

## 共同要求

```text
用途：风格化概念美术。

资产类型：约 5:4 横构图的游戏卡面插画母版，只生成完整插画，不生成卡框。

输入图片：
图片 1 是唯一视觉参考，只负责确定冻结的“明亮旅行绘本”风格：
轻盈的手绘水彩和彩色墨线、温暖的象牙色纸张、可见的纤维纸纹、
不规则笔缘、松弛的胡桃色和彩色轮廓线，以及冻结色板。

不得复制参考图的拼贴排版、示例物件、文字或说明标签。
没有现有随从或其他内容参考图。

构图：
一个主要随从；用于解释机制的盟友、召唤物、倒影或预览必须保持次要。
主体一级轮廓在缩略图中清楚可辨。
必要主体与机制关系位于中央 80% 安全区。
外圈 7% 不放置必要信息，不裁切主体。

光照：
以晨间至下午的漫射日光为主光。
至少一半画面属于亮部或中亮部。
保留浅色纸张和蓝天；阴影保持开放、柔和并带有颜色。
魔法、灵魂和炉火光只作为局部强调。

禁止：
卡框、UI、标题条、可读文字、字母、数字、Logo、签名、水印、
照片写实、光滑 3D、动漫抽卡渲染和厚重不透明数字绘画。

身体结构、肢体数量、甲片结构、服装结构和一级轮廓可以自由设计；
不得复用现有随从形象。
```

## 铸魂

```text
创造一个全新的铸魂随从。

种族主题：
灵魂被封入铠甲、兵器或机关中，成为拥有生命的造物。
画面必须清楚表现“被封印的发光灵魂正在驱动锻造物”，不能只是普通人穿着
铠甲，也不能只是没有灵魂语义的通用机器人。

玩法语言：
护盾、嘲讽、亡语；获得护盾、失去护盾、相邻随从和受击后触发。

画面表现：
主要铸魂以坚定的保护姿态承受一次清楚的攻击。
外层半透明护盾在冲击中出现裂纹，并释放蓝金色共鸣，传向附近作为次要轮廓
出现的友方造物；与此同时，内层新的护盾光开始重新形成。

一缕从破损旧铠甲中升起的灵魂回声用于暗示亡语，但画面不能阴森。
这些元素只负责表达机制关系，不规定装备数量或身体结构。

铸魂视觉语言：
锤炼铁、盾缘、铆钉、修补缝、淬火蓝、誓约绳结，以及简单的叶片或火焰形
工艺纹样。不得出现星辰、星座、月相、占星符号或宇宙纹样。

场景：
白昼中开放的旅行铠甲工坊庭院，使用浅色石地、简单工作台和低细节远景。
```

## 荒灵

```text
创造一个全新的荒灵随从。

种族主题：
山林、兽魂、藤蔓和古老生命力。
主体应像从林野兽性、根系、树皮、藤蔓、叶片、苔藓与山石中自然孕育出的
古老生命。

玩法语言：
亡语、嘲讽；友方死亡、荒灵死亡、召唤物和死亡后增益。

画面表现：
主要荒灵以保护道路、阻挡敌人的姿态站立。
附近存在体量较小的叶片与兽魂召唤物。
其中一个正在消散的召唤物化为叶片与温暖绿色生命力，能量沿藤蔓和根系传递，
使幸存的主体与其他召唤物长出新的枝叶并得到强化。

从倒下自然材料中升起一层半透明兽魂回声，暗示亡语但不出现尸骸和血腥。
不规定召唤物数量，也不规定全族身体结构。

场景：
白昼中的明亮山林隘口，浅色岩石、蓝色远山、蕨类和古树作为低细节背景。
```

## 星契

```text
创造一个全新的星契随从。

种族主题：
观星者、符文术士、月相学派和命运契约。
主体必须像一名与契约、商业和命运反馈紧密相关的天象学者，而不能只是装饰性
星空动物或普通宇宙生物。

玩法语言：
战吼、护盾、溅射；购买法术、使用法术、刷新商店、发现、出售随从，以及将
结果反馈到下一场战斗。

画面表现：
星契学者位于明亮的露天商店观星台，以如同登场或揭示身份的姿态完成战吼式
亮相，并从旋转的黄铜丝带陈列架上选取一张没有文字的法术页。

适量硬币交换和一个空置的小展示座用于暗示购买与出售。
月相圆盘与抽象、不可阅读的符文在陈列架上转动，使法术页展开并发生变化，
表达刷新商店和发现新选择。

被选中的法术生成半透明保护屏障，并分叉成水彩波纹，触及远方战斗预览中的
多个次要训练轮廓，表达护盾、溅射和下一场战斗反馈。

不规定物件和选项的精确数量。

场景：
白昼中的高地旅行商店兼观星亭，包含蓝天、浅云、轻帆布、远山和低细节货架。

允许抽象魔法符号，但不得组成可阅读语言。
```
