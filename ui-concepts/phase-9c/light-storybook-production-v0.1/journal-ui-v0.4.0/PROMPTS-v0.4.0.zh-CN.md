# v0.4.0 日记式 UI 生成说明

## 唯一视觉输入

`ui-concepts/phase-9b/style-tiles/style-tile-d-wandering-storybook-v0.1.png`

文件名虽保留早期编号，但它由 v0.3.3 冻结包指定为现行的明亮旅行绘本唯一图片参考。
每次生成仅输入它一张图，并只继承媒介、纸纹、彩色墨线、色板与白昼曝光。

## 共同 Prompt 块

```text
明亮旅行绘本；轻盈手绘水彩和水粉、彩色胡桃墨线、暖象牙纸纤维；
清澈蓝绿、薰衣草、浅棕和局部金色；开放白昼、主体与背景明确分离。
参考图不复制人物、道具、文字或构图。
画面不生成可读文字、数字、Logo、水印、卡框或 UI 控件；不使用夜景、
暗角、黑色留白、烟尘、照片写实或炉火主照明。
```

## 资产变量

| 资产 | 画幅 | 内容变量 | UI 安全区 |
| --- | --- | --- | --- |
| 封面 | 3:4 | 绿皮蓝脊旅行日志、地图、罗盘、橡叶与蓝色丝带 | 右上用于标题/按钮。 |
| 目录 | 16:9 | 象牙纸、四角旅途饰物、虚线路径 | 中央 70% 留给目录文字。 |
| 战士 | 2:3 | 旅行战士、圆盾、披风、白昼草径 | 身体外缘保持浅色。 |
| 法师 | 2:3 | 观测学者、星盘、行杖、高地观测台 | 背景低细节。 |
| 盗贼 | 2:3 | 轻装向导、钥匙环、望远镜、明亮集市路 | 背景低细节。 |
| 锁定 | 2:3 | 非身份化斗篷背影、上锁日记、叶与水晶 | 仍保持明亮，锁定条件由 UI 文案表达。 |
| 荒野 | 16:9 | 林间岔路、河流、远山、荒灵鹿 | 中上部留标题区。 |
| 星轨高原 | 16:9 | 白昼高地、星环地标、观测台、紫晶 | 不用夜空表达星契。 |
| 铸魂熔城 | 16:9 | 太阳照明的白石/赤陶工艺城、清水渠、局部机关心核 | 不用烟尘和炉火作为主氛围。 |
| 结局 | 16:9 | 完成的旅行日志、三种旅途纪念物与开阔山谷 | 上部留结局文字区。 |

运行时 UI 只载入导出的无文字 Sprite；章节名称、被动、锁定条件、解锁通知和按钮
均由现有 Unity `Text`/`Button` 层渲染。
