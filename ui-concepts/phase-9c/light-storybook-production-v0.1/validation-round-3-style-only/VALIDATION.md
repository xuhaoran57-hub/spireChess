## 人工复核

- 三张卡面不再复刻现有随从：分别形成鸟首锻造旅者、溪流林木巨灵和丝带状星旅
  生物，一级轮廓差异明显。
- 三张背景均为无旧图输入的新构图：移动高塔车队、开放式旅行商亭、无路线的明亮
  山谷地图。
- 六张图的水彩纸纹、蓝天、象牙纸白、青绿色与暖土色保持在同一绘本语言内。
- 主菜单左中区域、商店中央台面和地图中部地形带都保留了后续 UI 叠加空间。
- 未发现可读文字、卡框、按钮、水印或整图压暗。

## 结论

仅使用 style tile、完全移除内容图输入后，样本的角色轮廓和场景构图显著摆脱了旧
资产惯性，同时比 Round 2 更亮。该结果说明此前“生成结果仍与旧图相近”的主要
原因不只是文字硬约束，内容参考图本身也在高强度地锁定主体和构图。

这一轮适合作为新的探索基线。它证明“风格参考”和“内容参考”应分离，但尚不能
直接批量替换正式随从：下一步应由项目侧只给出每张卡的必要语义，例如职业、能力
和叙事目标，再逐项添加，避免重新引入身体、道具和镜头模板。
