## 本轮修复

- `RaceOrSpellType` 从 `InfoPanel` 子树移到卡牌根节点，并固定在普通/金色
  卡框之上；Full 使用 `16` 号字与 `168×24` 安全区，Compact 使用
  `13` 号字与 `112×19` 安全区。
- `AbilityLabelRow` 保留序列化兼容，但在 Full/Compact 下永久隐藏，不再显示
  “亡语 +2”“随从发现”“刷新”等分类说明。
- 等级书签扩大为 Full `32×40`、Compact `22×28`，数字字号固定为
  `22/16`。
- 攻击和生命徽章扩大为 Full `68×30`、Compact `46×21`，数字字号固定为
  `22/16`；四位数仍会按安全区自动缩放，重新渲染普通数值后恢复基准字号。
- 底部身份文字缩进中央安全区，避免与放大后的攻防徽章重叠。
